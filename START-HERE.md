# Start here, Jamal

This folder is everything needed to turn your Study Book and Intel into one private website, built by Claude Code. Do these steps in order, one at a time. If you get stuck on any step, stop and ask Claude. Nothing here can break your current Study Book or Intel; they keep working while this is built.

## What you'll create (all free to start)
1. **GitHub account**: stores the website's code, like Google Drive for code. It keeps every old version, so mistakes can be undone.
2. **Cloudflare account**: puts the website online (free, business use allowed) and stores photos.
3. **Supabase account**: handles your login and saves your progress and notes.
4. **Anthropic API (application programming interface) key**, optional at first: lets the website ask Claude to check your task answers (the Enter button). It's pay-per-use. Set a monthly spending limit when you create it.

## Steps

**Step 1: GitHub (5 minutes).** Go to github.com → Sign up. Use an email you check. Pick a simple username. Turn on two-step login when it asks.

**Step 2: Give this folder to Claude.** Come back to this chat and say "GitHub is ready." Claude will:
- create a private project (called a repository) named `aila-areeqa-studio`, and
- load this whole starter pack into it.

You'll be asked once to connect GitHub to Claude. Say yes.

**Step 3: Open Claude Code on the web.** Go to claude.ai/code. Pick the `aila-areeqa-studio` repository. Open `prompts/PHASE-1.md`, copy everything below the line, paste it in, and send.

**Step 4: Do the account steps Claude Code asks for.** Partway through, it will ask you to create the Cloudflare and Supabase accounts and paste a few keys into settings. It will tell you exactly where, one step at a time. Never paste keys into a chat with anyone else.

**Step 5: Check Phase 1 yourself (10 minutes).**
- Log in with your email link.
- Study → Continue. You should land on **Lesson 5, slide 5**. Lessons 1–4 should show as done, with your old answers still there.
- Intel → you should see **Run 17 · October 29, 2026** and every tab you know.
- Press Enter on a task answer and check that the coaching shows.

Tell Claude anything that looks different from before.

**Step 6: Phase 2.** Only after Phase 1 feels right, paste `prompts/PHASE-2.md` into Claude Code. That turns on daily Intel, the weekly, monthly and 3-month reports, and your 3 new lessons a week.

## What it costs

- **Later:** when your partner and media crew join, or photos pass 10 GB, about $25 a month for Supabase Pro plus about $0.015 per GB of photos per month.

## Keep doing in the meantime
